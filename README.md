`Python` `FastAPI` `LangChain` `ChromaDB`
`Hugging Face` `Gemini API` `LangGraph`

### 💡 What I built

* 🤖 Developed an **Agentic RAG application** using Gemini API and LangGraph.
* 🧠 Implemented a **multi-agent architecture** for intelligent document querying.
